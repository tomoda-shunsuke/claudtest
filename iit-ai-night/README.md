# IIT AIナイト 参加受付フォーム

東京都情報産業協会 技術部会「IIT AIナイト（事例共有＋ピザ）」の参加受付ページです。
申込フォームと、パスワード付きの参加者管理画面が1つのHTMLに入っています。

| ファイル | 中身 |
| --- | --- |
| `index.html` | 申込フォーム＋ログイン＋管理画面 |
| `Code.gs` | 申込データをGoogleスプレッドシートに保存するバックエンド |

---

## 現在の動作：メールで受け取る

申込ボタンを押すと、申込内容を本文に差し込んだメールの作成画面が開き、参加者がそのまま送信します。宛先は `index.html` の `CONFIG.MAIL_TO` です。

```js
var CONFIG = {
  MAIL_TO: "info@webedge.jp",   // 申込メールの宛先
  SEATS_NOTE: "残席 約10名",     // 画面に出す残席の目安。申込が入ったら手で更新します
  ...
};
```

サーバーを用意しないため設定は不要ですが、次の点にご注意ください。

- 参加者がメールを送信して初めて申込が届きます（作成画面で止めてしまうと届きません）。メールソフトが開かない参加者向けに、完了画面に「申込内容をコピー」ボタンと宛先を表示しています
- 残席は自動計算できないため、`SEATS_NOTE` を手で更新してください
- 管理画面は残っていますが、この状態では**自分の端末で入力した分しか表示されません**

自動集計まで必要になったら、下の手順でスプレッドシート保存に切り替えられます。切り替えると残席の自動計算と定員オーバーの防止も有効になります。

---

## スプレッドシート保存に切り替える手順（約5分・任意）

### 1. スプレッドシートを作る
[Googleスプレッドシート](https://sheets.new)で新しいファイルを作ります。名前は自由です。
（「申込」シートはスクリプトが自動で作るので、手動で用意する必要はありません）

### 2. Apps Script を開く
メニューの **拡張機能 → Apps Script** を開きます。

### 3. コードを貼り付ける
エディタの中身をすべて消し、`Code.gs` の内容を貼り付けます。
先頭の設定を書き換えてください。

```js
var ADMIN_PASSWORD = "ここに管理画面のパスワードを設定";  // 必ず変更してください
var CAPACITY       = 25;    // 定員
var NOTIFY_TO      = "";    // 申込通知を受け取るアドレス（空なら通知しない）
var SEND_CONFIRM   = true;  // 申込者へ受付確認メールを送る
```

管理画面のパスワードはこのファイルの中だけに置かれ、公開ページには含まれません。

### 4. ウェブアプリとしてデプロイする
**デプロイ → 新しいデプロイ → 種類の選択（歯車）→ ウェブアプリ** を選び、

- **次のユーザーとして実行**：自分
- **アクセスできるユーザー**：**全員**

を設定して **デプロイ** を押します。

> 「アクセスできるユーザー」を「全員」にしないと、Googleアカウントを持たない参加者が申し込めません。

初回は承認画面が出ます。**詳細 → （プロジェクト名）に移動 → 許可** と進んでください。

### 5. URLを貼り付ける
表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/.../exec`）をコピーし、
`index.html` の `CONFIG.API_URL` に貼り付けます。

```js
var CONFIG = {
  API_URL: "https://script.google.com/macros/s/XXXXXXXXXXXX/exec",
  ...
};
```

これで完了です。以降の申込はスプレッドシートに1行ずつ記録され、管理画面から確認できます。メールの作成画面も引き続き開くので、不要であれば `CONFIG.MAIL_TO` を空にしてください。

## 使い方

- **申込フォーム**：`index.html` をそのまま開いた状態
- **管理画面**：ページ最下部の「主催者ログイン」→ `ADMIN_PASSWORD` を入力

管理画面でできること

- 申込件数・参加者合計・残席・事例共有できる人数・懇親参加人数・参加費合計の集計
- 申込一覧（詳細を開くとメール、電話、事例内容、アレルギー、備考まで表示）
- ステータス変更（受付済／確認済／キャンセル）。キャンセルは人数と残席から自動で除外されます
- 会社名・氏名・事例内容での絞り込み、ステータス・事例共有での絞り込み
- CSV書き出し（Excelで文字化けしないUTF-8 BOM付き）
- 申込の削除

## 運用上の注意

- **定員を変えるときは2か所**：`Code.gs` の `CAPACITY` と `index.html` の `CONFIG.CAPACITY` を同じ値にしてください。定員の判定はサーバー側（`Code.gs`）が行います。
- **`Code.gs` を編集したら再デプロイが必要です**：デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ。URLは変わりません。
- **フォームと管理画面は同じURL**です。参加者にリンクを渡すと「主催者ログイン」ボタンも見えます（入るにはパスワードが必要です）。隠したい場合はフッターのボタンを削除してください。
- **メール送信の上限**：無料のGoogleアカウントは1日100通までです。今回の規模なら問題ありません。
